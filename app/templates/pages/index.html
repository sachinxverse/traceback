{# --------------------------------------------------------- how it works #}
Three steps to reconnect

From "missing" to "mine again"

1
Report it

Submit a Lost or Found report with photos, description, date and location — or scan an institution's QR poster to file it exactly where it happened.

2
Get matched

The engine compares image similarity, wording, distance and timing, and shows a ranked score breakdown — never hidden, always explainable.

3
Verify & recover

The owner submits a claim with details only the true owner would know. A human reviewer approves it, hands the item over, and recovery is confirmed by both sides.

{# ------------------------------------------------------------- trust row #}

Institution network

Transparent scoring

Every match shows which signals were used and how strong each one is. A match is a recommendation, never a verdict.
